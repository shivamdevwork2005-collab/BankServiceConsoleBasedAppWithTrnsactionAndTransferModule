# 🏦 BankService Project

A console-based Bank Management System developed using Core Java.

## 🚀 Features

- Open New Bank Account
- Close Bank Account
- Deposit Money
- Withdraw Money
- UPI Transactions
- Transaction History
- Find Account using Account Number
- Multiple Bank Services
- Loan Services
- Insurance Services
- Automatic Account Number Generation
- Sender and Receiver Bank Details
- Account Balance Management

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- HashMap
- HashSet
- Interfaces
- Inheritance
- Encapsulation
- Polymorphism
- Method Overriding
- Exception Handling
- Java Collections
